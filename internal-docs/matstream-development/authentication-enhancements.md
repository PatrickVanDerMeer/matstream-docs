# Authentication enhancements

Saved at the user's request on 9 November 2026 for future MatStream authentication enhancements.

Reference: [OWASP Authentication Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html).

Consult this reference when planning authentication changes, including password policy, MFA, account recovery, session reauthentication, and protection against account enumeration. Recheck the current guidance when implementing an enhancement.

The discussion included email codes with a browser remembered for 30 days. This remains a future consideration, not an approved implementation request or a claim of standards-compliant MFA.

Workspace authentication policies introduced in future work must be configurable by a workspace administrator through the application UI, with useful defaults and preservation of customizations when setup is rerun.
