# Print Templates — End User Guide

## What are Print Templates?

Print Templates let you generate professional PDF or Excel documents directly from MatStream — for example a Purchase Order, Pick List, Pack List, or Sales Order — using data that is already in the system. You do not need to copy anything into Word or Excel manually; MatStream fills in all the fields for you.

## How do I print a document?

Open the entity you want to print (for example, a Purchase Order). In the toolbar at the top of the page you will see a **Print** button with a small dropdown arrow. Click it to see all the print templates that have been set up for that type of record. Click the one you want and the file will download to your computer automatically.

## What file formats can I get?

Most templates produce a **PDF**, which is suitable for sending to suppliers, customers, or printing on paper. Some templates are set up to produce an **Excel file (.xlsx)** instead, which is useful when you want to review or adjust the data before printing.

## Why is the Print button empty or disabled?

The Print button shows only templates that an administrator has linked to the category of the current record. If no templates have been linked yet, the menu will show "No templates assigned". Contact your administrator to have a template added for that document type.

## Can I choose which template to use?

Yes. If more than one template has been set up for a category, they all appear in the dropdown. For example, you might have "Purchase Order — A4" and "Purchase Order — US Letter" as separate options.

## The document downloaded but some fields are blank. What should I do?

This usually means the template was not designed to include that particular field, or the data is missing from the record itself. Check that the record is fully filled in and contact your administrator if fields that should appear are consistently blank.

## Can I edit the document after downloading?

PDF files are read-only by design. If you need an editable version, ask your administrator whether an Excel output format can be configured for that template. Excel output lets you adjust values or formatting before printing.
