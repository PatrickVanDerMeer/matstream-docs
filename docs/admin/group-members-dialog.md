# Editing group members

The **Edit members** dialog allows administrators to add and remove 
workspace users from a group, and to set optional expiry dates on 
memberships.

---

## Opening the dialog

From the **Edit Workspace Group** dialog, click the person icon button 
in the top-right corner of the **Members** tab.

---

## Layout

The dialog is split into two panels:

**Available users (left)** — all workspace users who are not currently 
members of this group. You can filter the list by typing in the search 
box above it.

**Members (right)** — the users who currently belong to the group, 
along with an optional **Until** date for each membership.

---

## Adding users

To add one or more users to the group:

1. Select one or more users in the **Available users** list on the 
   left. Hold Ctrl or Shift to select multiple users.
2. Click **Add >>** to move the selected users to the **Members** list 
   on the right.

You can also double-click a user in the left list to add them 
immediately without selecting first.

To add all available users at once, click **Add all**.

---

## Removing users

To remove one or more users from the group:

1. Click a row in the **Members** grid on the right to select it.
2. Click **<< Remove** to move it back to the **Available users** list.

To remove all members at once, click **Remove all**.

---

## Temporary access (Until date)

Each row in the **Members** grid has an optional **Until** date column. 
If set, the user's membership in the group expires on that date — 
after which they lose the permissions granted by the group.

To set an Until date:

1. Click the **Until** cell in the relevant row.
2. Select a date from the date picker.
3. Leave the field empty for permanent membership with no expiry.

!!! tip
    Use the Until date for contractors, temporary staff, or users who 
    need elevated access for a specific project period. This is more 
    reliable than remembering to remove access manually.

---

## Saving

- **Save & Close** — saves all membership changes to the database and 
  closes the dialog. The Members tab in the group dialog refreshes 
  to show the updated member list.
- **Cancel** — discards all changes and closes the dialog.
